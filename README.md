# rkv — Learn Rust by Building

**rkv** is a small key-value store built as a Project-Based Learning exercise.

The goal is not to copy the implementation. The goal is to build your own version while learning Rust with an AI tutor.

You will encounter ownership, borrowing, lifetimes, enums, collections, error handling, modules, testing, and basic systems programming concepts.

## Getting started

1. Install Rust stable and Cargo.
2. Create a new Project in ChatGPT.
3. Copy [TUTOR_RULES.md](TUTOR_RULES.md) into your Project instructions.
4. Add [MILESTONES.md](MILESTONES.md) and [PROJECT_CONTEXT.md](PROJECT_CONTEXT.md) as reference material.
5. Create your own empty Cargo project.
6. Start a conversation with your AI tutor and ask for the first milestone.

**Important:** Do not ask AI to write Rust code for you. The purpose is to learn how to solve problems independently.

## How learning works

Your AI tutor gives you one small milestone at a time. You implement it, run the compiler, investigate errors, and submit your work for review.

The tutor should explain concepts, ask questions, and guide your reasoning without providing ready-made solutions.

A milestone is complete when you understand *why* your implementation works, not merely when it compiles.

## Reference implementation

This repository contains the completed implementation and its Git history.

You can explore the commit history to understand how the project evolved. Avoid reading ahead if you want to solve the exercises independently.

## Philosophy

**Build first. Understand deeply. Use AI as a teacher, not a code generator.**
