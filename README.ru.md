# rkv — Изучаем Rust через практику

**rkv** — небольшой key-value store (хранилище «ключ — значение»), созданный в процессе изучения Rust по методике **Project-Based Learning (PBL)**.

Главная цель — не скопировать готовую реализацию, а самостоятельно написать программу, постепенно разбираясь в Rust с помощью ИИ-наставника.

В процессе ты познакомишься с ownership, borrowing, lifetimes, enum, коллекциями, обработкой ошибок, модулями, тестированием и основами системного программирования.

## Как начать

1. Установи Rust stable и Cargo.
2. Создай новый проект в ChatGPT.
3. Скопируй содержимое [TUTOR_RULES.md](TUTOR_RULES.md) в инструкции проекта.
4. Добавь [MILESTONES.md](MILESTONES.md) и [PROJECT_CONTEXT.md](PROJECT_CONTEXT.md) в качестве справочных материалов.
5. Создай собственный пустой Cargo-проект.
6. Открой новый чат с ИИ-наставником и попроси выдать первый milestone.

**Важно:** не проси ИИ писать за тебя Rust-код. Смысл обучения — самостоятельно находить решения, а не получать готовую программу.

## Как проходит обучение

ИИ-наставник выдаёт небольшое задание — milestone.

Ты самостоятельно реализуешь его, запускаешь компилятор, разбираешь ошибки и отправляешь результат на проверку.

Наставник помогает вопросами, объясняет концепции Rust и направляет твоё мышление, но не предоставляет готовые решения.

Milestone считается завершённым не тогда, когда программа просто компилируется, а когда ты можешь объяснить, **почему она работает именно так**.

Учебный план гибкий. Необязательно проходить все этапы в строго заданном порядке.

## Готовая реализация

В этом репозитории находится законченная версия проекта.

История Git-коммитов показывает, как программа постепенно развивалась: от простого чтения пользовательского ввода до модульного приложения с тестами.

Если хочешь пройти обучение самостоятельно, **не изучай готовую реализацию заранее**. Используй репозиторий как справочный материал, а не как источник кода для копирования.

## Философия проекта

**Учись писать код, а не просить ИИ писать его за тебя.**

Ошибки компилятора — часть обучения. Не бойся ошибаться, задавать вопросы и возвращаться к непонятным темам.

Цель проекта — научиться самостоятельно проектировать программы, понимать управление памятью и уверенно работать с Rust.
